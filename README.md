# Interview Questions & Company Assessment Trackers

A collection of company-oriented interview and assessment preparation resources. Each company folder contains its relevant practice material and, where available, a deployed webpage tracker.

## Company trackers

| Company | Preparation resource | Webpage tracker |
|---|---|---|
| IBM | [IBM assessment practice notes and usage guide](./ibm/README.md) | [Open IBM Assessment Practice Lab](./ibm/IBM_Assessment_Practice_Lab.html) |

## Repository structure

```text
Interview-Questions/
└── ibm/
    ├── IBM_Assessment_Practice_Lab.html
    └── README.md
```

## Adding another company

Create a folder using a lowercase company name, add its preparation resources and a folder-level `README.md`, then add a row to the company tracker table above. Include the company name, a short resource description, and the deployed webpage URL (or repository-relative webpage link).

## Notes

- Company-specific question sets should be described as sourced datasets or practice collections, not guarantees of future assessment content.
- For static HTML trackers, GitHub Pages or another static hosting provider can be used to publish a deployed URL. The relative link above works directly from the repository even before deployment.
